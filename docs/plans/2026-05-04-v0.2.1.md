# sitesnap v0.2.1 — Localization + `--version` + HTML Detection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship sitesnap v0.2.1 by adding `--version` / `-v` flag, detecting HTML-as-sitemap user error with a friendly Japanese hint, and translating all user-facing CLI text (errors, HELP, progress messages) to Japanese while leaving worker progress codes (`[desktop] 1/3 ok URL`) and library-originated exceptions in English.

**Architecture:** Pure text changes plus two small features. No new modules. No new runtime dependencies. Existing test files are updated to match the new Japanese strings; two test files gain new tests (`tests/cli.test.mjs` for `--version`, `tests/sitemap.test.mjs` for HTML detection). Output structure (`meta.json`, file paths) is unchanged.

**Tech Stack:** Node 22+, Playwright (already installed), fast-xml-parser (already installed), built-in `node:test` runner.

- [ ] **Step 3: Update `fetchXml` in `src/sitemap.mjs`**

Find the existing `fetchXml` function:

```js
async function fetchXml(url) {
  const res = await fetch(url, { headers: { 'user-agent': USER_AGENT } });
  if (!res.ok) throw new Error(`${res.status} ${url}`);
```

Replace with:

```js
async function fetchXml(url) {
  const res = await fetch(url, { headers: { 'user-agent': USER_AGENT } });
  if (!res.ok) throw new Error(`${res.status} ${url}`);
  const ct = res.headers.get('content-type') || '';
  if (/text\/html/i.test(ct)) {
    throw new Error(
      `URLがHTMLを返しました（sitemapではありません）: ${url}\n` +
      `ヒント: 単一ページなら 'sitesnap page <url>' を使うか、\n` +
      `実際のsitemap位置を確認してください（/sitemap.xml や /robots.txt 内）。`
    );
  }
  return parser.parse(await res.text());
}
```
