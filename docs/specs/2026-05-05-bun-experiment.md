# Bun移行実験ノート

実験開始日: 2026-05-05
ブランチ: `experiment-bun`

## 目的

1. Bunを実際に触って学ぶ
2. sitesnapがBunで成立するか検証する(特にPlaywrightの動作)
3. 段階的に進めて技術的ボトルネックの位置を切り分ける

## スコープ(3段階)

| 段階 | 内容 |
|---|---|
| ① パッケージマネージャ | `pnpm` → `bun install`への切替 |
| ② ランタイム | shebangとscriptsを`node` → `bun`に変更 |
| ③ TypeScript化 | `.mjs` → `.ts`、テストを`bun:test`に移行 |

## 評価基準(各段階共通)

- 既存テストが通る
- `sitesnap site <URL>`で実機スクショが撮れる(②以降の最重要項目)
- 体感速度に明らかな悪化がない

## 判断ルール

| 結果 | 対応 |
|---|---|
| ①②③全部成功 | mainにマージ |
| ①②成功・③失敗 | ③のコミットを捨てて①②だけmainへ |
| ①成功・②失敗 | ①だけmainへ(または全部捨てる) |
| ①から壊れる | ブランチ削除して撤退 |
